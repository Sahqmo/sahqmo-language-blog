# 하루 루틴 한눈에 보기

아침, 점심, 저녁으로 나눠서 부담 없이 이어 갈 수 있는 루틴을 만들어 봤습니다.

## 아침: 단어 복습

출근이나 등교 전에 10분 정도만 써서 어제 외운 단어를 훑어봅니다. 소리 내어 읽으면 기억에 더 오래 남습니다.

* 어제 외운 단어 20개 훑어보기
* 틀린 단어는 따로 표시해 두기
* 예문이 있으면 *한 번 더* 소리 내어 읽기

## 점심: 짧은 듣기

식사하면서 짧은 일본어 오디오나 영상을 듣습니다. 다 알아듣지 못해도 괜찮고, 익숙한 표현이 들리는지만 확인합니다.

> 완벽하게 이해하려고 하지 말고, 계속 듣는 것이 먼저입니다.

### 듣기 자료 고르는 기준

1. 속도가 너무 빠르지 않을 것
2. 자막이나 대본이 있을 것
3. 5분 안팎으로 짧을 것

## 저녁: 문법과 작문

하루 한 문장이라도 직접 써 보는 것이 좋습니다. 처음에는 짧고 단순한 문장으로 시작합니다.

#### 예문 모음

* 今日はとても疲れました。 (오늘은 매우 피곤했습니다.)
* 週末に友達と映画を見に行きます。 (주말에 친구와 영화를 보러 갑니다.)
* この本は思ったより難しいです。 (이 책은 생각보다 어렵습니다.)

표 바로 아래에 이어지는 문단입니다. 표와 글 사이 간격이 어떻게 보이는지 확인할 수 있어요.

## 코드로 보는 학습 기록

공부 시간을 기록하는 간단한 스크립트 예시입니다.

```js
const log = []

function study(minutes, topic) {
  log.push({ date: new Date().toISOString(), minutes, topic })
}

study(25, '단어')
study(15, '문법')
console.log(log.reduce((sum, e) => sum + e.minutes, 0)) // 40
```

기록해 두면 `한 주에 몇 분 공부했는지`가 눈에 보여서 동기부여가 됩니다.

##### 작은 팁

꾸준함이 속도보다 중요합니다. 하루를 건너뛰어도 *다음 날 다시 시작하면* 됩니다.

###### 마무리

여기까지 읽어 주셔서 감사합니다. 제목 단계별 간격, 인용 블록, 목록, 표, 코드 블록이 모두 한 글에 들어 있어서 스타일을 점검하기에 좋습니다.
