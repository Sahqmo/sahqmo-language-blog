# 티스토리 블로그를 이 사이트 디자인으로 꾸미는 방법

## 방법

1. **기본 스킨 고르기**: 관리자 → 꾸미기 → 스킨 변경에서 `Book Club`, `Poster`처럼 단순한 스킨을 하나 적용한다.
2. **스킨 편집 열기**: 꾸미기 → 스킨 편집 → **html 편집**. `skin.html`, `style.css`, `images`를 직접 고칠 수 있다.
3. **CSS부터 교체**: `style.css`에 이 사이트의 색·서체·간격을 넣는 게 가장 안전하다. `[##_..._##]` 치환자와 `<s_...>` 블록은 건드리지 않고, 클래스에 스타일만 입힌다.
4. **글 본문 영역**: 본문 컨테이너는 `.tt_article_useless_p_margin`, `.contents_style` 같은 클래스인 경우가 많다. 브라우저 개발자 도구로 실제 클래스를 확인한 뒤 스타일을 입힌다.
5. **적용**: 저장 후 "변경사항 적용". 적용 전에 스킨 미리보기로 확인할 수 있다.

## 이 사이트에서 가져올 수 있는 것

- **색상** (라이트): 배경 `#f7f7f6`, 카드 `#ffffff`, 본문 `#2a2a28`, 흐린 글자 `#7d7d79`, 선 `#e4e4e1`, 포인트 초록 `#5f7a5c`, 연한 초록 `#e3eadb`.
  다크 모드는 `@media (prefers-color-scheme: dark)`로 추가. 실제 값은 `src/index.css` 맨 위 변수 참고.
- **서체**: Noto Serif / Noto Serif KR (Google Fonts). 코드 블록은 Consolas.
- **본문 스타일**: 문단 첫 줄 들여쓰기(`text-indent: 1em`, 제목 바로 다음 문단 제외), 제목 단계별 위쪽 간격(H1 30px / H2 24px / H3 18px / H4~6 14px), 인용 블록(초록 막대 + 연한 배경), 표·코드 블록 둥근 모서리, 줄 간격 `line-height: 2.09`.
- **코드 문법 색**: highlight.js 같은 라이브러리를 `<script>`로 불러서 같은 색 변수(`--tok-*`)를 입힌다. 티스토리 스킨은 JS 삽입을 허용한다.
- **구조가 달라 수정이 필요한 것**: 카테고리 칩, 카드형 글 목록, 스크롤 시 부드럽게 나타나는 효과.

## 한계

- 서버 코드를 쓸 수 없고 글 편집기도 티스토리 자체 에디터라서, **글쓰기 화면은 바꿀 수 없다.** 바꿀 수 있는 건 보이는 블로그 화면뿐이다.
- 홈의 도넛 차트처럼 데이터를 계산하는 부분은 치환자로 카테고리 목록만 얻을 수 있고, 글 수 비율은 JS로 직접 만들어야 한다.
- 본문에 인라인 스타일이 붙는 경우가 있어서, CSS가 안 먹을 때는 `!important`가 필요할 수 있다.

## 다음 단계

쓰는 스킨의 현재 `skin.html`을 가져오면, 그 구조에 맞춰 `style.css`와 `skin.html` 초안을 만들 수 있다. (치환자가 깨지지 않게 구조를 먼저 봐야 한다.)
